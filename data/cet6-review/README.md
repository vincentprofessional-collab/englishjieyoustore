# 六级真题来源与质量核验

本轮范围为2015—2026年，沿用中高考列表、题卷与作答组件。已移除六级知识点入口、详情及40份知识点导入数据。2011年旧题型网络稿按用户决定另存待补，不发布。

## 数据与作答

- 76套、3507道不重复来源题；另按原题分成写作、听力、选词填空、长篇阅读、仔细阅读、翻译六种专项，专项沿用真题的题目ID、答案和出处。
- 49套57题含听力；22套32题含写作、阅读和翻译；5套仅有写作与翻译。页面明确原资料的收录范围，不生成缺失题。
- 49份录音对应核验通过；开头与本套题面匹配，结尾推广检查通过，移除封面与文字元数据。
- 279道题有两次提取一致、正文强匹配且同卷的明确答案字母，可自动判分；其余3228道题提交后查看原答案页核对，不推测答案字母。
- 听力和仔细阅读采用单选；选词填空使用A—O词库且不重复使用；长篇阅读使用原文实际段落字母，允许重复；写作和翻译保留原题及参考范文/译文。
- 图片卷直接保留净化后的原题页，避免OCR改写错字。Word题卷使用源文本。原题图片可打开清晰图；参考答案和解析默认折叠，提交后查看；专项一次显示一套。
