# 中考英语模块设计方案

## 1. 目标

在“英语考试”导航菜单下新增“中考英语”入口。模块面向全国各地中考英语资料，提供两种核心学习路径：按年份和地区进入完整真题模考；按题型、年份和地区进入专项训练。

本阶段只确定信息架构、交互规则和内容呈现方式，不改变现有雅思功能。

## 2. 导航与首页

导航结构：

```text
英语考试
├── 雅思
└── 中考英语
```

中考英语首页只使用中文标题“中考英语”，不显示英文副标题。标题下方放置两个主要入口：

- 真题模考：完整试卷、正式计时、提交后统一查看结果与解析。
- 专项训练：按题型集中练习，默认不计时，可手动使用计时器。

首页沿用雅思页面的克制学习工具风格：奶油色背景、深绿色重点、金色辅助色，保持宽度、间距、按钮和导航系统的一致性，不堆叠大量装饰卡片。

## 3. 真题模考流程

```text
真题模考 → 选择年份 → 选择地区 → 确认 → 进入完整试卷
```

年份按上下纵向排列。地区按用户常用地区优先显示，例如北京、上海、天津、广东、江苏、浙江、山东、河北、河南、四川、湖北、湖南、陕西、福建、安徽、辽宁、重庆，其他地区置于“其他省市”。后台应保留调整地区顺序的能力。

确认页只在年份和地区都选定后启用确认按钮。确认后直接进入对应卷子，不再二次选择。

### 计时

- 进入试卷后立即自动开始倒计时。
- 优先使用该试卷原文标注的考试时长。
- 原卷没有明确考试时长时，使用统一默认时长，并在数据中明确标记来源。
- 倒计时到 `00:00:00` 后继续计时，以负数表示超时，例如 `-00:08:35`。
- 提交时记录总用时、是否超时和超时时长。

模考答题过程中不显示解析内容；提交后进入结果与解析状态。

## 4. 专项训练流程

```text
专项训练 → 选择题型 → 选择年份 → 选择地区 → 确认 → 进入专项练习
```

专项训练默认不启动计时。页面提供统一计时器按钮，用户可以手动开始、暂停和继续；该计时只记录训练用时，不限制答题或提交。

题型入口应根据资料实际结构逐步建立，至少覆盖：

- 听力
- 单项选择／语法
- 完形填空
- 阅读理解
- 任务型阅读／阅读表达
- 词汇与综合填空
- 补全对话
- 书面表达

题型名称允许按不同地区的真实题型差异做同义归并，但不能把原卷不存在的题型强行套入所有地区。

## 5. 考试工作台

真题模考和专项训练共享同一套工作台骨架，借鉴雅思听力、阅读、写作页面：

- 顶部显示“中考英语”、年份、地区、卷别和计时器。
- 中部显示题目与答题组件。
- 底部显示题号导航、上一题／下一题和提交按钮。
- 题号导航显示已作答、未作答和当前题状态。
- 真题模考和专项训练使用相同的控制样式，但计时启动规则不同。

题型布局：

- 听力：音频播放器、题目区和播放进度。
- 单项选择：题干、选项和题号导航。
- 完形填空：文章与填空选项。
- 阅读理解、任务型阅读、阅读表达：左侧文章、右侧题目，左右独立滚动，沿用雅思阅读的分栏逻辑。
- 综合填空：短文与输入框。
- 书面表达：写作要求、大文本输入框和字数统计。

阅读类分栏中，左侧文章保持可见，右侧题目可以逐题切换；题目变长时不改变文章列的定位。

## 6. 提交、答案与解析

用户提交后，每一道题都显示：

- 用户答案
- 正确答案
- 对错结果
- “解析”按钮

“解析”按钮不只提供给错题，答对题也必须提供。点击后在当前题目旁或下方展开解析背景框，右侧提供“关闭”按钮。解析框默认关闭，避免提交后页面过长。

解析内容来自同一套试卷对应的解析版文件，并按题号与原卷题目匹配。解析版没有成功匹配题号时，不伪造解析内容；该题进入待整理状态并保留原题结果。

## 7. 内容数据分层

资料目录中同时存在年份、省市、原卷版、解析版、听力音频、复习资料和一模／二模／三模资料。因此数据模型需要至少区分：

- 年份
- 地区／城市
- 卷别（A 卷、B 卷或联合地区卷）
- 原卷文件
- 解析文件
- 音频资源
- 题目类型
- 题号与题目内容
- 试卷考试时长及其来源

正式历年真题与复习资料、模拟卷、知识清单分开管理，不在“真题模考”入口混合展示。

## 8. 资料盘点结论

当前资料主要覆盖 2019—2024 年。不同年份下包含大量省级、市级试卷，且大多数原卷与解析成对存在；题型结构随地区不同而变化。实现前应先建立文件索引和原卷／解析配对规则，再抽取题目数据，不能依赖统一全国卷结构。

## 9. 后续实现顺序

1. 建立资料索引：年份、地区、卷别、原卷／解析／音频配对。
2. 在导航中加入“中考英语”并建立首页入口。
3. 实现真题模考的年份—地区选择与完整试卷工作台。
4. 实现按题型—年份—地区选择的专项训练工作台。
5. 接入分地区考试时长和负数超时计时器。
6. 建立提交结果、答案匹配和解析框交互。
7. 选取少量代表性地区试卷进行结构验证，再扩展资料覆盖范围。

## 10. 暂不确定且实现前需单独确认的事项

- 首批上线哪些年份和地区。
- 各类题型的自动判分规则，尤其是阅读表达和书面表达。
- 听力音频与题目时间轴是否已经完整可用。
- 原卷没有考试时长时的统一默认时长。
- 解析版题号不规范时的人工校对流程。
