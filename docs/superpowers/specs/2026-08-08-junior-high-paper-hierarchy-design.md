# 中考英语试卷层级与交互版式设计

## 目标

将不同地区、不同年份的中考英语试卷统一整理为“部分 → 小节/题型组 → 题目”的层级结构，避免小节说明重复出现在题目卡片中，并让短文、音频、图片和填空题与对应题目保持同组呈现。

## 当前问题

1. 解析器把“第一部分/第二部分”和“第一节、Ⅰ、Ⅱ、Ⅲ、A、B”等标题混在同一层，部分说明文字还会被误识别为题目。
2. 页面把 `paper.assets.audio` 一次性渲染在整套试卷顶部，听力音频没有跟随对应小节。
3. DOCX 中存在纯白或极小的占位图片；当前显示逻辑会保留空白图，并可能隐藏相邻的短文文字，造成页面只有空白框。
4. 题目卡片右上角重复显示小节说明，例如“第一节 听句子……（共5小题）”，造成题干和说明混在一起。
5. 词汇填空、首字母填空、选词填空、综合填空和短文填空目前多以题目下方文本框呈现，不能在原文数字空格位置直接作答。

## 设计方案

### 1. 数据模型

在现有 `JuniorHighPaper` 上增加规范化的 `parts` 数据，不删除现有 `sections`，以便兼容北京专用试卷和旧数据。

```ts
type JuniorHighQuestionGroup = {
  id: string;
  marker?: string;
  title: string;
  instructions: string[];
  blocks: JuniorHighBlock[];
  displayBlocks?: JuniorHighBlock[];
  questionIds: string[];
  audio?: string[];
  inputMode?: "choice" | "inline-blank" | "text";
};

type JuniorHighPart = {
  id: string;
  marker?: string;
  title: string;
  instructions: string[];
  groups: JuniorHighQuestionGroup[];
};
```

每道题继续保留 `sectionId`/`groupId`，并增加可选的 `partId`。`sections` 继续作为原始提取兼容字段；结构化试卷优先使用 `parts` 渲染。

### 2. 层级识别规则

- 大部分识别：`第一部分`、`第二部分`、`第Ⅰ卷`、`第Ⅱ卷`、`Part I` 等明确标记。
- 小节识别：`第一节`、`第二节`、`Ⅰ/Ⅱ/Ⅲ/Ⅳ/Ⅴ`、`（一）/（二）`、`A/B/C/D` 以及地区试卷使用的“听短文、信息转换、配对阅读”等题型标题。
- 如果原卷没有显式“部分”，则将最外层题型标题作为部分，并把其下的说明和题目组作为小节。
- 纯说明文字不得创建题目；只有包含明确题号、空格或可识别选项的内容才创建题目。
- 原始标题文本保留在 `title`，不依赖某一个地区的固定符号。

### 3. 短文、图片与音频

- 每个题目组先渲染组标题和说明，再渲染本组音频、图片/表格、短文原文，最后渲染对应题目。
- 音频从顶层集中显示改为挂在 `JuniorHighQuestionGroup.audio`。若文件名无法精确对应单题，则放在最近的听力小节，而不是整套试卷顶部。
- 过滤纯白、透明或无实际内容的占位图片；保留有文字、图表或插图的有效图片。
- 即使图片被过滤，也保留相邻的文字和表格块，不能因为图片存在而隐藏短文。
- 删除“【此处可播放相关音频，请去附件查看】”等占位文字，用真实音频控件替代。

### 4. 题目卡片与填空交互

- 题目卡片标题只显示“第 X 题”，不再在右侧重复显示部分/小节说明。
- 小节说明只在小节标题下显示一次，说明字体小于部分标题和小节标题。
- 所有填空类题型使用 `inline-blank` 模式：在短文中的数字空格处放置输入框；输入值以题目 ID 保存，提交后在原空位置显示正确答案、对错状态和解析按钮。
- 没有连续短文、只有单句的词汇填空，仍在题干空格位置嵌入输入框，不再单独放置大文本框。
- 选择题继续使用选项按钮；开放性阅读表达和作文继续使用文本域。

### 5. 字体层级

- 部分标题：24px。
- 小节/题型组标题：18px。
- 小节说明：14px，使用较浅颜色。
- 短文正文：16—17px。
- 题目与选项：15—16px。

这样可以明确区分“第一部分 听力”“第一节 听句子”“小节说明”和“第1题”。

## 兼容与降级

- 北京 2024/2023 专用版保持现有专用版式，只移除题目卡片重复的小节标签，并沿用其已有音频/图片字段。
- 缺少可识别层级的旧数据使用“原有 section 作为 part、题目组作为 group”的降级方式，不阻塞试卷进入网站。
- 找不到精确音频归属时，音频挂到对应听力小节并显示一次；不再在页面顶部重复显示。

## 测试与验收

使用 2024 天津、2022 新疆、2023 广东三种结构作为代表样本，并覆盖全部 30 套批量试卷：

1. 解析测试验证部分、小节、题目组和题号范围正确，说明文字不进入题目。
2. 资源测试验证音频挂在题目组、纯白图片不进入显示块、短文文字仍然存在。
3. 渲染测试验证题目卡片不重复显示小节说明，填空输入位于数字空格处。
4. 运行全部中考测试、TypeScript 检查和生产构建。
5. 在代表样本页面检查：层级字体、短文内容、音频位置、图片尺寸、选择题和填空题交互均正常。

## 不在本次范围内

- 不改变题目原文、答案和解析内容。
- 不把不同地区的题型名称强行改成同一种中文名称；只统一层级字段和展示规则。
- 不删除有效的原卷插图、表格或听力音频。
