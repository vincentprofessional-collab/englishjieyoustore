# 中考英语试卷可交互内容展示设计

## 目标

区域中考英语试卷页面只展示可交互题卡及其必要的阅读材料，移除已经被题卡替代的 Word 原卷段落和无交互的 Word 说明，同时保留文章、图片、表格、音频、写作提示及现有计时、解析、批注、高亮功能。

## 背景与问题

当前 `structured` 试卷同时渲染 `section.blocks` 和由同一批 Word 段落解析出的题卡。题目、选项和说明因此会在页面重复出现。部分试卷还包含未被解析成题目的 Word 段落，导致页面混入大量原卷排版内容。

## 设计

### 1. 转换阶段生成可展示内容

在 `extract-junior-high-paper.py` 生成每套试卷 JSON 时，为每个 section 的源块增加展示角色或生成等价的 `displayBlocks`：

- `question-source`：题号、题干、选项及其连续源段落。题卡已经提供交互，不直接展示。
- `passage`：位于题目源段落之外、且不是标题或作答说明的文章段落。保留，供阅读和完形作答。
- `image`、`table`、`audio`：保留。图片和表格作为原卷材料，音频作为听力控件。
- `instruction`、封面和未转换为题目的普通 Word 说明：不直接展示。

题目源块的范围由当前题目的 `sourceBlockIds` 到下一题源块之前的所有块确定，避免只隐藏题号而留下选项和题干重复。section 标题由页面标题显示，不再从源块重复输出。

### 2. 页面渲染只使用可展示内容

`StructuredPaperContent` 改为读取 `displayBlocks`；对旧 JSON 没有该字段时使用同样规则的运行时兼容过滤。页面不再把完整 `section.blocks` 作为原卷文档渲染。

每个 section 的展示顺序保持原卷顺序：必要的文章段落、图片/表格/音频、交互题卡。题卡继续使用现有的选择按钮、文本框、提交反馈和逐题解析，不改变题号导航。

没有任何交互题且没有写作任务的纯 Word section 不渲染其普通段落；写作提示继续由 `writingTasks` 和写作输入区域负责。原有字数统计和人工评分提示保持不变。

### 3. 数据与兼容边界

- 不修改北京 2023/2024 专用页面的现有布局。
- 不修改 IELTS 页面、导航栏、后台或听力资源。
- 不删除源文件路径、文件名和解析文件名，这些字段仍用于题卷标识和解析来源。
- 图片、表格、音频资源文件不删除，只调整展示入口。

## 验证标准

1. 重新生成的区域卷 JSON 含有可展示内容标记，题目源段落不会作为普通文本渲染。
2. 30 套区域卷均能打开；有题卡的 section 不再出现重复题干/选项；纯说明 section 不出现 Word 原文块。
3. 阅读和完形文章段落、原卷图片、表格、音频仍可见或可播放。
4. 选择题、填空题、文本题、写作输入、提交、计时、解析、全屏、批注和高亮行为与修改前一致。
5. 既有中考数据、页面结构测试、TypeScript 检查和生产构建全部通过。

## 备选方案及取舍

- 仅在 React 页面中添加过滤：改动小，但后续重新转换试卷仍可能重新引入重复内容。
- 每套试卷手工维护隐藏块清单：控制精确，但无法支持后续批量上传。
- 采用转换阶段的统一展示层并在页面兼容旧 JSON：一次解决当前数据和后续批量导入，且保留旧数据的安全降级，因此采用本方案。
