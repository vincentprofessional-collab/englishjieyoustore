# 中考英语试卷结构化版式修复设计

## 目标

让现有 30 套批量导入的中考英语模考/真题达到北京卷的最终交互质量，同时保留每个地区原卷的题型顺序、分值结构和版式差异。

统一能力包括：计时、题号导航、全屏、批注、高亮、提交答卷、逐题答案、逐题解析、图片/表格展示和写作字数统计。

不把其他地区强行改成北京卷的 37 题结构。地区原卷的听力、完形、阅读、填空、翻译、对话和写作顺序必须保留。

## 当前根因

当前北京卷使用结构化字段（分组原文、题目、答案、解析、写作任务），批量试卷则全部使用 `layout: "generic"`。批量提取器只读取段落，再把表格集中追加到文末；图片没有保留在原文中的位置，WMF 图片被丢弃；题号、答案和解析只用全篇正则匹配。因此批量试卷只能以“原文大文本 + 题目卡片”显示，无法保持原卷结构。

## 设计方案

### 1. 结构化试卷文档模型

批量试卷改用可渲染的文档模型，每套试卷包含：

- `sections`：按原卷顺序排列的部分，例如听力、单项填空、完形填空、阅读理解、补全对话、写作；
- `blocks`：每个部分中的段落、表格、图片、音频和题组；
- `questionGroups`：题组原文与对应题目范围；
- `questions`：唯一的绝对题号、原卷显示题号、题型、选项、答案和解析；
- `writingTasks`：真实的写作任务、提示表格/图片、开头结尾、字数要求和字数统计规则；
- `sourceAssets`：图片、音频和表格的来源位置及渲染地址。

北京卷现有字段继续兼容，逐步转换到同一模型，避免影响已经确认的北京卷页面。

### 2. DOCX 提取流程

提取器按 Word 文档 XML 的原始顺序读取 `paragraph`、`table` 和 `drawing`，生成有序 block 流。媒体文件使用关系 ID 映射到对应 block，不再把图片集中放在页面顶部；WMF 等原格式先转为浏览器可用的 PNG，再保留原始文件名和位置。

题目识别以“当前 section + 当前 question group”为上下文，不再对整篇文档做无状态的数字正则。每个地区模板负责声明：部分边界、题号是否重启、题型、题量、开放题规则和写作部分位置。

### 3. 地区模板

先建立可复用的题型族模板，而不是为每份试卷复制一套组件：

- 北京 37 题模板：继续使用当前已确认的最终布局；
- 听力 + 语言知识 + 阅读 + 写作模板：覆盖天津、安徽、福建、河南、湖南、陕西、广西等；
- 听说应用/读写综合模板：覆盖广东 2022/2023；
- 多部分非选择题模板：覆盖上海、河北、四川、江苏等含填空、翻译、任务型阅读的试卷；
- 复合阅读/表格模板：支持题组原文、表格和图片在原位置上下排列。

模板只负责结构和交互，题目内容全部来自试卷数据，不在组件里写死北京题号范围。

### 4. 统一交互外壳

`JuniorHighPaperWorkbench` 保留现有计时、全屏、批注、高亮和提交能力，改为根据 `sections` 渲染；题号导航使用唯一 question ID，不依赖题号数字唯一。选择题、填空题、翻译题、任务型阅读和开放题分别使用对应输入控件。

提交后只显示当前题的答案和解析；解析边界由数据中的 question ID 决定，不能跨到下一题。写作任务显示真实提示，并持续显示英文词数统计。

### 5. 质量门禁

每套试卷在进入目录前必须通过以下校验：

1. 题量与原卷 section 声明一致，题号在 section 内连续且可追溯；
2. 没有重复 question ID，题号重启也不会造成导航冲突；
3. 解析不能使用兜底文本，除非该题明确标记为人工评分；
4. 原卷图片、表格和音频均有可访问资源，并且绑定到正确 block 或题组；
5. 写作任务不能使用通用占位文案；
6. 选择题、填空题和开放题的答案字段符合各自题型；
7. 页面渲染不会重复显示完整原文和交互题目。

## 分阶段实施

### 阶段一：2024 年试卷

重建 14 套 2024 年试卷，优先修复题号、解析、表格/图片顺序和写作任务。每套通过结构校验和页面抽查后再进入目录。

### 阶段二：2023 年试卷

处理广东、江苏、浙江、山东、河北、湖南怀化 6 套，重点验证听说应用、阅读填空、任务型阅读和多部分写作。

### 阶段三：2022 年试卷

处理上海、新疆、河北、云南、四川、海南、甘肃、广东 10 套，重点验证中英混合题型、非选择题和多音频试卷。

每个阶段都先写失败测试，再修改提取器或渲染器；阶段完成后运行全量测试、构建和页面抽查。

## 非目标

- 不删除或覆盖原始 DOCX、解析 DOCX 和音频文件；
- 不改变已经确认的导航、后台、口语 Part 1/3 和北京卷最终布局；
- 不把不同地区的评分规则强行统一；
- 不用截图替代逐题交互内容。
