# 背单词与 PK

## 单人学习

- 分类学习每组 20 个词。模糊、生僻词回到本组队列，直到整组都标记为熟悉才展示小结。
- 小结的熟悉／模糊／生僻数量记录第一次分类，不被后续复习覆盖。
- 小结提供下一组、浏览本组、PK 本组、结束任务。最后不足 20 个词的组在 PK 中循环本组词汇至 20 题。
- 设置提供中英／英英。中英保留原有提示；英英在口语、写作考察中显示英文释义。
- “自建生词本”位于设置左侧。Excel 的一列英文词汇加入现有生词本，与文章收藏合并去重，保留已有词条信息。
- 生词本与学习设置沿用当前浏览器存储，不承诺跨设备同步。字典中已有的词汇沿用现有学习 API 补充释义；未知词汇保留原词，不自动编造释义。

## PK 规则

- 每场 20 题，四个释义选项，不显示例句。答对加 20 分，答错或超时得 0 分。
- 双方共享服务器开始时间；准备 3 秒，每题作答 10 秒，随后揭晓 1.5 秒。
- 揭晓前只显示对方是否已作答，不泄露本题正确性或通过累计正确数泄露答案。
- 同词汇书、同当前段位匹配。来自学习小结的“本组 PK”还要求同一组词汇。
- 等待 30 秒未匹配到对手时生成挑战链接；访客可直接参加链接友谊赛。挑战等待有效期 15 分钟。
- 有访客参与的场次不累计排名；登录用户邀请赛只有双方同意才计入排位。
- 胜者获得自己正确题分数加对方正确题分数；负者保留自己的正确题分数。正确题数相同按作答总用时决定胜负；两项相同为平局，双方保留各自分数。
- 所有答题和结算在数据库中以比赛行锁串行执行，已完成比赛不会重复累计积分。
- 掉线者的未答题按超时处理。在另一位参赛者读取状态时结算；双方均离线时由每分钟数据库任务完成结算。

## 段位和排行榜

积分、累计题数、正确率、胜率同时达标；胜率计算为 `(胜场 + 平局 / 2) / 总场次`。每本词汇书分别累计，积分不限上限，当前段位随累计成绩变化并保存历史最高段位。

| 段位 | 题数 | 积分 | 正确率 | 胜率 |
| --- | ---: | ---: | ---: | ---: |
| 白银 | 200 | 2,500 | 55% | 40% |
| 黄金 | 400 | 6,500 | 60% | 45% |
| 铂金 | 800 | 13,000 | 65% | 50% |
| 钻石 | 1,200 | 24,000 | 70% | 55% |
| 至尊星耀 | 1,600 | 40,000 | 80% | 60% |
| 最强王者 | 2,000 | 60,000 | 95% | 70% |

月、季、年榜按北京时间起算，展示本书排位赛积分前 100 名的头像、昵称、当前段位与周期积分。数据库直接汇总完整周期数据，避免 API 默认行数限制截断榜单。

## 部署

在现有 Supabase 数据库执行 `supabase/027_vocabulary_pk.sql`，需要启用 `pg_cron`。迁移仅创建 PK 专属表、索引、函数和每分钟结算任务；表启用 RLS，客户端角色不能直接访问，函数仅供服务端调用。

服务端沿用 `NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_ANON_KEY` 与 `SUPABASE_SERVICE_ROLE_KEY` 或 `SUPABASE_SECRET_KEY`。不把服务端密钥发送给浏览器。

Excel 使用按需加载的 SheetJS 0.20.3；文件不上传到服务器，最多 10 MB、10,000 行。没有新增收费语音服务。
