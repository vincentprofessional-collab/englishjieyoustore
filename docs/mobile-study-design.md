# 手机学习界面

范围：BBC、新概念和雅思听力复盘的精读、精听、写作与口语；保持现有米白底、浅蓝控件及教材内容。

以用户截图和录屏为依据：五个学习模式同排，模式设置与辅助工具分组；句子、译文、练习答案和提示依次排列；缩减空白和重复控件，触摸控件至少 40px，长句自然换行。

BBC／新概念使用一个手机底部播放器：泛读播放整篇，其他四种模式播放当前句，左右键切上一句／下一句。当前句的进度从零显示，时长为当前句时长。保留页面底部空间避免遮住练习。

雅思听力使用页面上方的主播放器。句子卡片点击后跳到主音频对应时间；不另放浮动或重复的句子播放器。保留试题与学习模式功能。

播放时突出当前词或答案位置，写作未揭晓的答案仍隐藏。查词长按 1.5 秒；滑动、拖动或普通点击不触发查词。桌面弹框在鼠标未进入时 1 秒收起，进入弹框可操作发音、收藏等功能。

验证：一个浏览器按手机与桌面视口顺序检查真实组件，检查长句、空词汇区、播放器边界与顺序切句、译文和字号，以及触摸拖放与长按。
